# 🌸 Seasons Switcher

A responsive **Seasons Switcher Web App** built using **HTML, CSS, Bootstrap, and JavaScript**.  
This project dynamically changes the background images based on the selected season — Spring, Summer, Autumn, or Winter 🌷☀️🍂❄️

## 💻 Features
✅ Switch between **4 seasons** (Spring, Summer, Autumn, Winter)  
✅ Each button dynamically updates **two responsive images** (for small and medium screens)  
✅ Fully **responsive layout** using Bootstrap  
✅ Clean, simple UI with smooth transitions  
✅ Uses **modular, readable JavaScript** with proper variable naming conventions  

---

## 🧠 How It Works
- The app displays an image of **all four seasons** initially.  
- When a season button is clicked:
  - The small image (`seasonImageSmall`) and medium image (`seasonImageMedium`) update to that season’s version.
  - Backgrounds change based on pre-defined image URLs.
