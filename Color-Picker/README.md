# 🎨 Color Picker

A simple and interactive color picker project built using HTML, CSS, and JavaScript.

## 🧩 Features
- Choose from 4 predefined colors.
- Instantly updates the background color of the page.
- Displays the selected color's HEX code.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap (for minor styling support)
