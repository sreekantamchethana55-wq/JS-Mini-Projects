# ➕ Addition Game

A fun **Addition Game Web App** built using **HTML, CSS, and JavaScript** 🎮  
It generates two random numbers and asks the user to find their sum.  
If the user enters the correct answer, they win — otherwise, they can try again!

## 💻 Features
✅ Generates **two random numbers** between 1 and 100  
✅ Validates the user’s input and displays feedback instantly  
✅ Shows **“Congratulations!!!”** for correct answers and **“Wrong”** for incorrect ones  
✅ Includes a **Restart** button to reset the game with new random numbers  
✅ Simple, responsive, and beginner-friendly project
