# 🎨 Random Color Generator

A fun and colorful **Random Color Generator Web App** built using **HTML, CSS, and JavaScript** 🌈  
Each time the user clicks the button, the background color of the page changes randomly from a predefined list of colors.

---

## 🧠 Assignment Description

In this assignment, the goal is to build a **Random Color Generator** that changes the background color of a container whenever the button is clicked.

---

## 🧩 Functional Requirements

### ✅ HTML Element IDs
| Element | ID | Class (if any) | Description |
|----------|----|----------------|--------------|
| `<button>` | `button` | — | The button that triggers the color change |
| `<div>` | `bgContainer` | `bg-container` | The container whose background color changes |

---

## 💻 Features
✅ Changes background color randomly from a predefined color list  
✅ Uses `onclick` event to handle button clicks  
✅ Clean, minimal UI  
✅ Beginner-friendly JavaScript logic  
✅ Great for practicing DOM manipulation and arrays
