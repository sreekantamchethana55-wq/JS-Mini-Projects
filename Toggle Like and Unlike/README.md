# 💙 Toggle Like & Unlike

A simple interactive **Toggle Like & Unlike** web app built using **HTML, CSS, and JavaScript**.  
When the user clicks the "Like" button, the puppy image, icon color, and button styling change to show a “liked” state 🐶❤️

## 💻 Features
✅ Click to toggle between **Like** ❤️ and **Unlike** 🤍  
✅ The **puppy image** updates dynamically  
✅ The **icon color** changes between grey and blue  
✅ The **button background & text color** switch smoothly  
✅ Simple and **responsive layout**

---

## 🧠 How It Works
- The **HTML button (`id="likeButton"`)** listens for a click event.
- On click:
  - The **image (`id="puppyImage"`)** changes its `src` attribute.
  - The **icon (`id="likeIcon"`)** color toggles.
  - The **button** color and background color toggle.
- Clicking again switches back to the unlike state.
