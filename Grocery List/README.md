# 🛒 Grocery List

A simple **Grocery List Web App** built using **HTML, CSS, and JavaScript**.  
This project dynamically generates a grocery list using JavaScript’s DOM manipulation methods — without writing any static HTML list items.

---

## 🧠 Assignment Description

In this assignment, the goal is to **dynamically create and display** a list of grocery items inside a container using **JavaScript DOM manipulation**.  
No static HTML list items should be used — everything is created using JS methods.

---

## 🧩 Functional Requirements

### ✅ HTML Element IDs
| Element | ID | Description |
|----------|----|-------------|
| `<div>` | `groceryListContainer` | The container where the entire grocery list will be displayed |

---

## 💻 Features
✅ Dynamically creates heading, container, and list items using JavaScript  
✅ Displays a styled grocery list inside the container  
✅ Clean layout and modern font styling using **Roboto**  
✅ Fully customizable grocery list array  
✅ Great practice for **DOM creation and looping**
