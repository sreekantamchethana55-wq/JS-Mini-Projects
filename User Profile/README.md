# 👩‍💻 User Profile Page

A simple **User Profile Page Web App** built using **HTML, CSS, and JavaScript** 💻  
This project dynamically creates and displays a user’s profile using data stored in a JavaScript object — including name, age, and profile image.

---

## 🧠 Assignment Description

In this assignment, the goal is to build a **User Profile Page** using DOM manipulation.  
All content (heading, image, and paragraph) should be created **dynamically** in JavaScript based on the values from the provided `profileDetails` object.

---
