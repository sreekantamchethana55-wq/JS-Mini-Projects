# 🎨 Button Maker

An interactive **Button Maker Web App** built using **HTML, CSS, and JavaScript** 💻  
This project allows users to dynamically customize a button’s **style properties** such as background color, font color, font size, font weight, padding, and border radius — all through input fields.

---

## 🧠 Assignment Description

In this assignment, the goal is to build a **Button Maker** app that updates the style of a button dynamically when the user clicks the “Apply” button.

The user can modify:
- Background color  
- Font color  
- Font size  
- Font weight  
- Padding  
- Border radius  

and immediately see the changes reflected on the custom button.

---

## 🧩 Functional Requirements

### ✅ HTML Element IDs
| Element | ID | Description |
|----------|----|-------------|
| `<input>` | `bgColorInput` | Input for background color |
| `<input>` | `fontColorInput` | Input for font color |
| `<input>` | `fontSizeInput` | Input for font size |
| `<input>` | `fontWeightInput` | Input for font weight |
| `<input>` | `paddingInput` | Input for padding |
| `<input>` | `borderRadiusInput` | Input for border radius |
| `<button>` | `customButton` | The button to which styles are applied |
| `<button>` | `applyButton` | Button that triggers style updates |
